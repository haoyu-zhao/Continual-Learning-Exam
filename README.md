# Continual Learning Exam (CLE)

**CLE Team**

[Homepage](https://haoyu-zhao.github.io/CLE/) · [Paper](https://haoyu-zhao.github.io/CLE/assets/continual-learning-exam.pdf) · [Hugging Face](https://huggingface.co/Continual-Learning-Exam)

Continual Learning Exam evaluates how AI agents acquire, retain, and reuse experience across professional workflows. Each task is a sequence of five connected assignments: passing a level unlocks the next, and later assignments build on earlier work.

## Benchmark

- **120 human-authored tasks**, developed by more than 50 domain experts.
- **600 levels** spanning 89 professional roles across 12 occupational domains.
- **Stateful environments** in which files, actions, and working state carry forward.
- **Rubric-based evaluation**, comparing one submission per level with diagnostic feedback and one opportunity to revise.

The [project website](https://haoyu-zhao.github.io/CLE/) includes the manuscript, reported results, benchmark documentation, and five illustrative mock task workflows.
